# AfuDesk v1.10.4

## Türkçe

- Bağlantı sonrası Windows ekran yakalama oturumunun açık kalmasına neden olan kaynak temizliği hatası giderildi.
- Pencere görünümü telefonun yatay/dikey oranına uygun açılır.
- Güncelleme bulunduğunda hesap ekranında belirgin Güncelle düğmesi gösterilir.
- Uygulamaya dönüşte yeni sürüm denetimi yenilenir; ağ hatasından sonra tekrar denenir.
- v1.10.3 açık pencere seçimi de bu pakete dahildir.

Telefon klavyesinin diktesi metin girişi üzerinden kullanılır. Bas-Konuş uzak Space tuşunu basar/bırakır; telefon mikrofonundan bilgisayara ses aktarımı henüz desteklenmez.

Gerçek telefonda güncelleme/klavye ve uzun süreli kaynak ölçümü henüz doğrulanmadı.

## English

- Stop Windows graphics capture when a session ends, including early exit paths.
- Respect the phone viewport orientation when opening remote windows.
- Show a visible Update action and refresh release checks when returning to the app.
- Includes the v1.10.3 open-window picker.

Push-to-talk sends remote Space key events; forwarding phone microphone audio is not implemented. Real-phone and long-duration resource checks remain unverified.
