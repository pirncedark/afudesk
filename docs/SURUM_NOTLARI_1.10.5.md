# AfuDesk v1.10.5

## Türkçe

- Konuşma Modu (Talk Mode) toggle butonu ve klavye kontrolü eklendi.
- Space tuşu ile bas-konuş (Push-to-Talk / PTT) yönlendirmesi entegre edildi.
- Sesli dikte (STT) ve Türkçe karakter girdileri optimize edildi.
- Mobil oturumda arka plan ve pencere odak yönetimi güçlendirildi.
- Önceki v1.10.4 mobil kaynak temizliği ve akıllı pencere seçimi düzeltmeleri dahildir.

## English

- Added Talk Mode toggle button and keyboard flow.
- Added Space key push-to-talk (PTT) forwarding for remote sessions.
- Optimized voice typing / speech-to-text (STT) and Turkish input handling.
- Enhanced window focus and mobile background session management.
- Includes previous v1.10.4 mobile resource cleanup and smart window picker fixes.
