## AfuDesk v1.10.3 — Smart Window Focus & Quick App Switcher

### Smart Window Selection
- **Direct Window Focus**: When no terminal window is currently running on the remote desktop, tapping the **Terminal / Window** button instantly presents a clean, sorted list of all active application windows (Google Chrome, Notepad, VS Code, File Explorer, Spotify, etc.) allowing direct focus with a single tap.
- **Dynamic Mode Switcher**: If terminal windows are present, users can switch between active terminals and all running application windows using the "Other windows" option.
- **Single Window Auto-Focus**: If only one application or terminal is active, AfuDesk focuses it immediately without requiring manual selection.

## AfuDesk v1.10.3 — Akıllı Pencere Seçimi ve Hızlı Uygulama Odaklama

### Akıllı Pencere Seçimi (Terminal Yoksa)
- **Doğrudan Açık Pencerelere Odaklanma**: Bilgisayarda açık bir terminal oturumu yoksa, mobil araç çubuğundaki **Terminal / Pencere** butonuna dokunulduğunda doğrudan açık olan gerçek uygulama pencereleri (Google Chrome, Not Defteri, VS Code, Dosya Gezgini, Spotify vb.) listelenir ve tek dokunuşla seçilen uygulamaya odaklanılır.
- **Dinamik Mod Geçişi**: Terminal açıkken terminaller öncelikli listelenir; kullanıcı dilerse "Diğer pencereler" seçeneğiyle açık olan diğer tüm pencerelere geçiş yapabilir.
- **Tek Pencerede Otomatik Odak**: Bilgisayarda yalnızca tek bir pencere açıksa, ek diyalog beklemeden doğrudan o pencereye odaklanır.
